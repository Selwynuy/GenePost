GenePost guide

Set up your Mac, hire your first agent, and get a post ready to publish.

Try the browser demo

The walkthrough plays silently when it comes into view. Follow the highlighted step or choose Try it to take over. Pick a café tasting, personal brand, or app update below the demo to start with its caption and photo or screenshot.

The demo uses sample captions and keeps publishing records in your browser tab. You can edit captions and add your own media. Calendar and Reports update as you schedule or mark sample posts published.

Demo photos by Danny Pérez and Kelly Sikkema on Unsplash.

Install and activate

GenePost 2 supports Apple silicon Macs running macOS 14 Sonoma or later. Use the Developer ID signed, notarized disk image linked from the GenePost website when the release is available.

  1. Open the DMG and drag GenePost into Applications. Eject the disk image, then open GenePost from Applications.
  2. Open Settings → License and paste the key in your Lemon Squeezy receipt. Select Activate this Mac.
  3. Install a supported Codex CLI and run codex login. Sign in with ChatGPT. In GenePost, open Settings → Connections and select Connect.

Activate on up to two Macs. A successful check lets you use licensed features offline for 30 days. AI requests and publishing require internet access. Use Verify license to refresh an activation or Deactivate this Mac before moving to a new one.

If macOS blocks an installer, check that you downloaded it from the official release page and contact support with the message.

Set up channels

Open Channels and save the exact profile, Page, or group URL and expected posting identity. Add multiple accounts on one platform if you use them for different brands. Group related accounts under a name like Morrow Coffee so you can reuse the same audience.

GenePost supports planning for Instagram, LinkedIn, Facebook, Threads, X, Reddit, and TikTok. Sign in to the correct account in your browser. Follow the channel’s rules for content, community access, and media.

Hire an agent

Open Specialists in the sidebar, or choose Browse specialists from Team. Search by name or skill, filter by specialty, and open a profile to see sample work. Choose Set up role to interview or hire that specialist.

  1. Open Team → Post a job. Describe the role and choose its brand group and channels.
  2. When Team shows new applications, open a profile to read their strengths and approach.
  3. Open Browse portfolios on the posted job to review a specialist’s sample work. You can invite them to interview or hire them directly while applications are coming in.
  4. Interview a candidate and tell them how you want them to work. Review Setup for this role before hiring. Those directions and rules carry into the agent’s profile.
  5. Assign a task in Team. Draft posts, plan a campaign, create an image, or select one teammate and choose Research for public sources. Use public details in the research question. The sources appear with the result.
  6. Choose Review outcome on a result to share what happened. Approve a useful lesson with Keep lesson. The teammate uses it in that brand’s future work.

Edit an agent’s profile to set its default model and reasoning level. The picker beneath a conversation lets you override those settings for that conversation. Each task keeps its selected model.

A green dot means Online. A teammate shows Working during an active task and Busy when work is queued. Open their profile to set Busy or Invisible.

Tasks run while GenePost is open. Keep the Mac awake for work in progress. Check the status in Team and use the saved result or retry an interrupted task.

Draft and publish

  1. Start a New Post or choose Review & edit on a Team result. Select the accounts and check the caption and media for each one.
  2. Choose Review Post and set a date and time. The scheduled item appears in your local Calendar and Queue.
  3. When you’re ready to publish, select the post in Queue. Use Copy caption & open and Show media in Finder. Review the account in your browser, paste the caption, attach media, and publish there.
  4. Return to GenePost and select Mark published after you confirm the post is live.

The calendar holds your publishing plan. Feed previews approximate the layout on each platform. Always check the final caption and media in the platform’s own composer.

Calendar and scheduling

Use Week or Month to check upcoming items across accounts. Filter by channel and status. Click a date to see its agenda, or open a planned item to inspect it in Queue. Check the displayed time zone before arranging a campaign.

For a batch of text posts, import a UTF-8 CSV from Calendar using channel_url, scheduled_at, and caption. Use saved channel URLs and future ISO 8601 times with offsets.

Save and resume drafts

Choose Save Draft when a post needs approval or more work. Open Drafts and select a row to resume the caption, media, account selection, or conversation. Use the saved account previews to compare versions before scheduling. Removing a draft leaves its library media available for reuse.

Use the media library

Media keeps a reusable collection of the photos and videos you import or generate. For example, import a tasting flyer once and attach it to both the launch post and the reminder.

  1. Open Media → Import and choose a photo or video. You can also paste a copied image from a post composer.
  2. Open the asset to check the file and preview it. Use its post action, or select it from the composer’s media menu.
  3. Review the attachment on each account’s preview. Use Show media in Finder in Queue to locate the file for the browser handoff.

Videos and images are stored locally. Keep an original backup. GenePost protects files referenced by drafts or scheduled posts from removal.

Read a publishing report

Open Reports and select a date range. Compare Published, Pending, and Needs attention by platform. These are GenePost’s records of publishing results, including posts you marked published.

Check that the platforms you intended to publish to have the expected counts. Investigate a missing result in Queue → History and review any unresolved item in Needs attention. Export CSV includes the scheduled time, platform, channel, status, and a post URL when recorded. Use platform dashboards for reach, impressions, or engagement.

Connect Codex

With GenePost open, go to Settings → Connections → Connect to Codex. Start a new local Codex chat and select or mention the GenePost plugin. Refresh the plugin list or reopen Codex if the integration is absent.

Example prompt: “Use GenePost to draft a tasting-event post for my coffee brand. Show me each account’s caption and media before you add it to the calendar.”

GenePost shares the saved context needed for the work you request. Use an explicit destination and time for scheduling. Confirm the result in Queue.

Claude Code setup

Advanced setup for a local Claude Code session. The GenePost MCP server gives the session access to GenePost’s local tools. GenePost’s built-in AI tasks still use your Codex connection.

claude mcp add --transport stdio --scope local genepost -- \
  /Applications/GenePost.app/Contents/MacOS/GenePost --chat-mcp

Run this in the project where you want the connection, adjusting the application path if needed. Keep GenePost open, start Claude Code in that project, and check /mcp. Review the server’s tools and only grant access in sessions you trust. See the Claude Code MCP guide.

Data and recovery

Use Settings → Connections → Advanced → Workspace Folder to find your local workspace. Quit GenePost before copying the folder to your own backup. Keep backups private since they contain posts, media, and account details. Store your license receipt separately. Mac activation is managed in Keychain.

Do not include your license key, sign-in credentials, or private drafts in support requests. Share the version number, action, and error message first.

Troubleshooting

Codex is disconnected
Run codex login status, sign in if needed, and reconnect in GenePost. Use Choose Codex… if the app cannot find the executable.
A model isn’t available
Reload the list in the conversation’s model picker, then choose a model your account can use.
The key has reached its activation limit
Deactivate an older Mac or contact support with your order number. Avoid sending the full key.
A planned post hasn’t appeared
Open its Queue item and complete the publishing handoff in your browser. Mark it published after checking the live post.
